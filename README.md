# Hollywood Animal Campaign Desk

Campaign Desk is an unofficial companion for planning film campaigns in Hollywood Animal. It ranks advertisers, shows which audiences and holidays fit your film, and estimates how many screenings to rent each week.

[Open Campaign Desk](https://santanudatta.github.io/HA-Campaign-Desk/)

## Plan a campaign

1. Add your film's tags under **Story elements**, or select **Try an example** to see a sample campaign.
2. Enter the film's **Commercial** and **Artistic** scores. Multiple genres start evenly split. You can enter each percentage from the game. The mix must add up to 100%.
3. Check **Advertiser picks** for ranked agencies. Open **Campaign breakdown** for audience matches, holiday bonuses, and suggested campaign timing.
4. Enter the **Owned screenings** you can assign to the film each week. The **Distribution calculator** uses your Commercial score and owned screenings to estimate weekly rentals.

Use **New film** to start another plan, **Rename** to give it a name, and **Saved films** to switch between plans. Each film saves its story elements, scores, and owned screenings in this browser. **Clear film** resets the active film’s story elements and scores. Use the trash icon to delete a saved film.
